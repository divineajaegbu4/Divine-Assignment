# 🧠 JavaScript Fundamentals — Take-Home Assignments

Welcome to the **JavaScript Fundamentals Assignment Collection!**

Each assignment focuses on a specific programming concept and includes a dedicated README explaining the task, the logic behind the code, and expected outputs.

## 🧰 Technologies Used

- **Language:** JavaScript (ES6+)

- **Runtime:** Node.js

- **Tools:** VS Code, Git & GitHub for version control

## 🚀 How to Run Any Assignment

1. Clone the repository to your local machine:

```bash
git clone https://github.com/adiva/Divine-Assignment.git
```

2. Navigate to the assignment directory:

```bash
cd Divine-Assignment
```

3. Run any file using Node:

```bash
node filename.js
```

Example:

```bash
node ecommerce-report.js
```

## 📝 Submission Workflow

Create a **new feature branch** for each assignment.
Example:

```bash
git checkout -b feat/ecommerce-report
```

- Commit your changes using meaningful commit messages.

- Push your branch and open a Pull Request to submit your work.
