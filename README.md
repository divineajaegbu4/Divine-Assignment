# Divine-Assignment

A simple JavaScript project that demonstrates different programming concepts using multiple files.

## Files Overview

* **processor.js**
  Handles basic array operations:

  * `calculateSum` → calculates the total sum of numbers in an array
  * `findMax` → finds the maximum number in an array
  * `average` → calculates the average of numbers in an array

* **todo-list.js**
  Provides simple task management functionality:

  * `displayTasks` → shows all tasks
  * `addTask` → adds a new task
  * `markTaskComplete` → marks a task as completed
  * `deleteTask` → removes a task

* **translator.js**
  Demonstrates conditional statements for language greetings:

  * Uses **if-else** and **switch** statements to output greetings in different languages
  * Supports Spanish (es), French (fr), German (de), and default English

## How to Run

1. Clone the repository:

   ```bash
   git clone <repo-url>
   ```
2. Navigate into the project folder:

   ```bash
   cd Divine-Assignment
   ```
3. Run any file using Node.js:

   ```bash
   node translator.js
   node processor.js
   node todo-list.js
   ```

## Purpose

This project is designed to practice and demonstrate:

* Conditional logic (`if` and `switch`)
* Array operations
* Task management with functions
* Clean code structure across multiple files
